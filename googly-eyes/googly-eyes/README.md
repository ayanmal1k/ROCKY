# Googly eyes

A Pen created on CodePen.

Original URL: [https://codepen.io/zzanggaeun/pen/YPNBxy](https://codepen.io/zzanggaeun/pen/YPNBxy).

Javascript-less (pure HTML and CSS) googly eyes that follow your mouse cursor. Uses the general sibling combinator (~) and a 3x3 grid of boxes that pick up the hover.
